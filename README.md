# Simplificador de Pesquisas

### Visa facilitar a busca de conteúdos específicos utilizando a própria fala do usuário para fazer uma pesquisa, que reprodz um áudio referente ao retorno do conteúdo encontrado.
<hr>

<p> Minha inspiração para desenvolver este projeto foi minha mãe, onde sempre que eu a auxiliava a resolver algo que envolvesse tecnologia, ela me dizia que não conseguia fazer de jeito nenhum (não que ela não saiba fazer uma busca no google), e pensando em algum produto que eu pudesse criar que eu nunca tinha visto, levantei essa ideia afim de ajudar outras pessoas com dificuldades parecidas.</p>
<hr>

### Portal onde a busca é feita:
<p>Atualmente a busca é feita diretamente no site do wikipedia, retornando pesquisas confiáveis a cada pesquisa. 
</p>
<p>Nas próximas versões do projeto, penso em trazer outras opções para deixar as pesquisas melhores e com o acesso simplificado possível.</p>
<hr>

### Tecnologias utilizadas
<p>Utilizei python tanto para desenvolver a parte do backend quando a parte de frontend (tkinter)</p>
